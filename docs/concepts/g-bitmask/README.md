# G 状压 DP 视觉概念板

> 状态：`实现完成，本地验收通过，待发布确认`
> 代表课程：`board`、`plug`

## 家族视觉语法

- 主母题：稀疏状态星座、合法邻边、当前 mask 与移动轮廓线。
- 主雕塑：玫瑰石英状态节点构成稀疏超立方体投影，只高亮当前状态及合法邻居。
- 课程路径：五个真实课程链接成为状态星座中的可访问节点。
- 家族矿材：玫瑰石英与拉丝黄铜，使用 `--grad-g`。
- 边界：不铺满二进制字符，不使用无法在移动端降维的炫技 3D。

## 逐课语义

| slug | 图例必须说明的一句话 |
|---|---|
| `board` | 合法行 mask 依据行内与相邻行约束逐行转移。 |
| `tsp` | 状态同时由已访问子集和当前终点决定。 |
| `cover` | 几何对象覆盖的目标集合通过按位或合成为 mask。 |
| `subset` | 子掩码沿 `(sub-1)&mask` 的关系被完整枚举。 |
| `plug` | 扫描轮廓逐格前进，插头配对编码已处理区域的连通性。 |

## 必须、允许与禁止

必须：状态空间保持稀疏；当前状态与合法边清楚；五课使用不同结构。

允许：移动端只显示当前状态和一层合法邻居；隐藏远端超立方体边。

禁止：显示大面积 0/1 字符墙；把 TSP 画成普通地图；继续称插头 DP 为选修。

## 移动端与保真

- 主雕塑保留当前核心、合法邻居与轮廓轨道。
- 课程路径在小屏退回顺序流，背景星座隐藏。
- 图集为 3×2，右下格为空；插头图例必须完整保留扫描线与配对端点。
