## 家族视觉语法

- 主母题：固定根、子树容器与自底向上的状态汇聚。
- 主雕塑：赭金树冠由多层状态容器组成，叶层结果沿枝干汇入父层和根。
- 课程路径：五个真实课程链接沿固定根的三层树冠分布。
- 家族矿材：赭金矿与旧黄铜，使用 `--grad-f`。
- 边界：F 强调固定根和合并；不出现 E 的巡游轨道或换根前后态。

## 逐课语义

| slug | 图例必须说明的一句话 |
|---|---|
| `select` | 父节点与子节点的选/不选状态存在明确冲突。 |
| `knapsack` | 子树背包逐个与父节点容量状态卷积合并。 |
| `diameter` | 最长与次长向下链在当前节点合成经过该点的直径。 |
| `cover` | 三类覆盖状态沿父子边组成合法组合。 |
| `count` | 子树计数按距离壳层或组合规模逐层汇入父节点。 |

## 必须、允许与禁止

必须：固定根明确；所有主流向自底向上；课程图例拥有不同的状态容器。

允许：移动端降低分枝数量，但必须保留至少两层合并。

禁止：增加根移动轨道；把五课都画成相同普通树；复用 A 的背包外形表示树上背包。
