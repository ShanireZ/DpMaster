## 家族视觉语法

- 主母题：沿索引前进的轨道、序列脊线和前驱关系。
- 主雕塑：一条带回落、抬升与分叉的折叠索引轨道；节点高度表达序列值，向前的连线表达状态来源。
- 路径结构稿：主雕塑的纵向线框版本，课程节点沿同一索引轴展开。
- 课程图版：统一使用 `640 × 390` 逻辑画布；具体课程决定是一维轨道、双序列还是二维矩阵，不能都退化成普通折线图。
- 家族身份色：深色 `#82ab9f → #5f8b7e`，浅色 `#37796a → #2b6153`，对应现有 `--grad-b`。
- DP 状态色：继续使用全站 `--viz-current`、`--viz-source`、`--viz-chosen`、`--viz-settled`、`--viz-invalid`，不得新建 B 类状态色。

## 七课一句话语义审计

| slug | 图版必须说明的一句话 |
|---|---|
| `path` | 当前格只从上一层的合法来源转移，最优值与方案数共享状态骨架但聚合方式不同。 |
| `maxseg` | 固定“以 `i` 结尾”，每步只在延续前段与从当前重启之间选择。 |
| `lis` | `f[i]` 从更早且更小的元素延伸；优化版用 `tails` 记录各长度的最小结尾。 |
| `lcs` | 两个前缀的末字符相等时走对角线，否则从删去一侧后的上方或左方取优。 |
| `edit` | 前缀对状态由删除、插入、替换三条有代价的来源边取最小值。 |
| `fsm` | 索引轴上存在多条状态轨道，状态保存会影响下一步合法选择的决策记忆。 |
| `count` | 状态与最值 DP 相同，但来源由取优改为求和，并以空前缀的一种方案为基底。 |

## 代表性试点

- `LIS`：验证一维序列、上升前驱链和 `tails` 层叠能否在同一图版内建立主次。
- `编辑距离`：验证 B 家族面对二维前缀状态时，仍能保留“双序列 + 索引推进”的身份，而不是被误认为 D 矩阵 DP。

## 必须、允许与禁止

必须：

- 分类主雕塑、路径结构稿和课程图版共享索引刻度、折线线型与节点语言。
- 深浅主题几何完全一致。
- 移动端保留关键索引、当前状态和来源关系。
- 课程图版提供可访问名称，SVG defs 使用实例唯一 ID。

允许：

- 主雕塑使用折叠金属、半透明纸层或线框材质。
- LCS、编辑距离采用二维矩阵，但两条输入序列必须清楚可见。
- 为复杂课程减少装饰性构造线。

禁止：

- 把七课都画成数据折线图。
- 使用 A 类背包轮廓、金色材质或容量刻度。
- 用家族灰青替代当前、来源、最优、非法等 DP 状态色。
- 在移动端直接裁掉右半图形或依赖横向页面滚动。
