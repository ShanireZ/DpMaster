# E 换根 DP 视觉概念板

> 状态：`已实现基线`
> 代表课程：`basic`、`distsum`

## 家族视觉语法

- 主母题：同一棵树上的根站、巡游轨道和父子双向信息流。
- 主雕塑：灰紫晶树保持拓扑不变，三处根站由轨道连接，青/金流向表现两次扫描。
- 课程路径：四个真实课程链接围绕同一棵树形成巡根路线。
- 家族矿材：灰紫晶与拉丝黄铜，使用 `--grad-e`。
- 边界：必须看见“根在移动”；不能成为 F 的普通固定根树冠。

## 逐课语义

| slug | 图例必须说明的一句话 |
|---|---|
| `basic` | 第一遍从子树向根汇总，第二遍把父侧答案传给子节点。 |
| `distsum` | 根跨边后，一侧节点变近、另一侧节点变远，数量决定总距离变化。 |
| `inout` | 子树内状态和父侧外状态在当前节点合成为完整状态。 |
| `center` | 最长和次长方向决定偏心距，并使候选中心向直径中部收敛。 |

## 必须、允许与禁止

必须：树拓扑在换根前后不变；两次扫描可区分；根站不等同于普通高亮节点。

允许：移动端减少根站数量和轨道装饰，但保留换根方向。

禁止：并排画两棵不同树冒充换根；使用 F 的子树容器作为主母题。

## 移动端与保真

- 主雕塑缩减外圈轨道密度，但保留根站与双向箭头。
- 课程路径改为单列，不裁掉父侧流。
- 图集为 2×2，四课均必须出现父侧信息或根移动线索。
