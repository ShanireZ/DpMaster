## 家族视觉语法

- 主母题：晶格平面、计算折页与重复变换。
- 主雕塑：两个橄榄矿矩阵平面围绕机械转轴折叠，结果平面从叠乘中形成。
- 课程路径：两个真实课程链接分别占据左右矩阵平面，保持紧凑。
- 家族矿材：橄榄石与黄铜铰链，使用 `--grad-d`。
- 边界：D 是坐标平面与线性变换，不是 B 的双序列，也不是普通科技网格。

## 必须、允许与禁止

必须：两课构图明显不同；折页必须说明变换而非装饰；二维状态保持真实坐标感。

允许：路径区比其他家族更短；移动端把两平面改为顺序叠放。

禁止：为填满页面制造虚假课程节点；把所有矩阵画成无语义背景网格。
